# Limitations

1. The current runner is a simulator, not a universal adapter for agent frameworks.
2. Failure localization is limited to observable invariant violations.
3. The included scenarios are hand-authored and small.
4. Local duration measurements are not production performance measurements.
5. The current benchmark is deterministic; stochastic LLM evaluation is not included.
6. Recovery policies are intentionally simple.
7. There is no authentication for the local API.
8. The system does not execute arbitrary user code.
9. The project does not claim superiority over Phoenix, Langfuse, AgentOps, or other existing tools.
10. A successful test suite demonstrates behavior on the included scenarios only.
